# 《史記．殷本纪》全譯

| 原文        | 譯文          | 註解 |
|:-------------|:------------------|:------|
|殷契，母曰簡狄，有娀氏之女，為帝嚳次妃。三人行浴，見玄鳥墮其卵，簡狄取吞之，因孕生契。|**殷**的始祖是**契**<sup>1</sup>，他的母親叫**簡狄**，是**有娀**<sup>2</sup>氏的女兒，**帝嚳**<sup>3</sup>的次妃。**簡狄**等三人到河裡洗澡，看見玄鳥掉下一颗蛋，**簡狄**揀起吞下，因而懷孕，生下了**契**。|<sup>1</sup>契（音同「謝」）;<sup>2</sup>娀（音同「松」）; <sup>3</sup>嚳（音同「酷」）|
|契長而佐禹治水有功。帝舜乃命契曰：「百姓不親，五品不訓，汝為司徒而敬敷五教，五教在寬。」|**契**長大成人，助**禹**治水有功，**舜**帝於是命令**契**說：「現在老百姓們不相親愛，父子、君臣、夫婦、長幼、朋友之間五倫關係不順，你去擔任司徒，認真地施行五倫教育。施行五倫教育，要本著寬厚的原則。」| |
|封于商，賜姓子氏。|**契**被封在**商**地，賜姓「**子**」。||
|契興於唐、虞、大禹之際，功業著於百姓，百姓以平。|**契**在**唐堯**、**虞舜**、**夏禹**的時代興起，為百姓做了許多事，功業昭著，百姓們因而得以安定。||
|契卒，子昭明立。昭明卒，子相土立。相土卒，子昌若立。昌若卒，子曹圉立。曹圉卒，子冥立。冥卒，子振立。振卒，子微立。微卒，子報丁立。報丁卒，子報乙立。報乙卒，子報丙立。報丙卒，子主壬立。主壬卒，子主癸立。主癸卒，子天乙立，是為成湯。| 契死之後，他的兒子昭明繼位。昭明死後，兒子相土繼位。相土死後，兒子昌若繼位。昌若死後，兒子曹圉繼位。曹圉死後，兒子冥繼位。冥死後，兒子振繼位。振死後，兒子微繼位。微死後，兒子報丁繼位。報丁死後，兒子報乙繼位。報乙死後，兒子報丙繼位。報丙死後，由兒子主壬繼位。主壬死後，由兒子主癸繼位。主癸死後，由兒子天乙繼位。這就是**成湯**。 | 圉（音同「語」）|
|成湯，自契至湯八遷。|從**契**到**成湯**，曾經八次遷都。||
|湯始居亳，從先王居，作帝誥。|到**成湯**時才又定居於**亳**，這是為了追隨先王**帝嚳**，重回故地。**成湯**為此寫了《帝詰》，向**帝嚳**報告遷都的情況。||
|湯征諸侯。葛伯不祀，湯始伐之。|**成湯**在**夏朝**為方伯<sup>1</sup>，有權徵討鄰近的諸侯。**葛伯**不祭祀鬼神，**成湯**首先徵討他。|<sup>1</sup>方伯，即一方諸侯之長|
|湯曰：「予有言：人視水見形，視民知治不。」|**成湯**說：「我曾說過：人從水中的倒影可以看見自己的形貌，從民眾可以知道一個國家治理得好或不好。」||
|伊尹曰：「明哉！言能聽，道乃進。君國子民，為善者皆在王官。勉哉，勉哉！」|**伊尹**說：「英明啊！善言聽得進去，道德才會進步。治理國家，撫育萬民，凡是有德行做好事的人都要任用為官。努力吧，努力吧！」||
|湯曰：「汝不能敬命，予大罰殛之，無有攸赦。」作湯征。|**成湯**對**葛伯**說：「你們不能敬順天命，我就要重重地懲罰你們，概不寬赦。」於是寫下《湯征》，記載了征**葛**的情況。||
|伊尹名阿衡。阿衡欲奸湯而無由，乃為有莘氏媵臣，負鼎俎，以滋味說湯，致于王道。|**伊尹**名叫**阿衡**。**阿衡**想求見**成湯**而苦於沒有門路，於是就去給**有莘**氏做陪嫁的男僕，背著飯鍋砧板來見**成湯**，藉著談論烹調滋味的機會向**成湯**進言，勸說他實行王道。||
|或曰，伊尹處士，湯使人聘迎之，五反然後肯往從湯，言素王及九主之事。|也有人說，**伊尹**本是個有才德而不肯做官的隱士，**成湯**曾派人去聘迎他，前後去了五趟，他才答應前來歸從，向**成湯**講述了遠古帝王及九類君主的所做所為。||
|湯舉任以國政。|**成湯**於是舉用了他，委任他管理國政。||
|伊尹去湯適夏。既醜有夏，復歸于亳。入自北門，遇女鳩、女房，作女鳩女房。|**伊尹**曾經離開**商湯**到**夏桀**那裡，因為看到**夏桀**無道，十分憎惡，所以又回到了**商**都**亳**。他從北門進城時，遇見了**商湯**的賢臣女（汝）鳩和女房，於是寫下《女鳩》、《女房》，述說他離開夏桀重回商都時的心情。||
|湯出，見野張網四面，祝曰：「自天下四方皆入吾網。」|**成湯**外出遊獵，見郊野四面張著羅網，張網者祝禱說：「願從天上來的，從地下來的，從四方來的，都進入我的羅網！」||
|湯曰：「嘻，盡之矣！」乃去其三面，祝曰：「欲左，左。欲右，右。不用命，乃入吾網。」|**成湯**聽了說：「噯，這樣就把禽獸全部打光了！」於是把羅網撤去三面，讓張網者祝禱說：「想往左邊走的就往左邊走，想向右邊逃的就向右邊逃。不聽從命令的，就進我的羅網吧。」||
|諸侯聞之，曰：「湯德至矣，及禽獸。」|諸侯聽說了這件事，都說：「**湯**真是仁德到極點了，就連禽獸都受到了他的恩惠。」||
|當是時，夏桀為虐政淫荒，而諸侯昆吾氏為亂。|恰逢此時，**夏桀**施行暴政，荒淫無道，還有諸侯**昆吾**氏也起來作亂。||
|湯乃興師率諸侯，伊尹從湯，湯自把鉞以伐昆吾，遂伐桀。|**商湯**於是舉兵，率領諸侯，由**伊尹**跟隨。**商湯**親自握鉞指揮，先去討伐**昆吾**，轉而又去討伐**夏桀**。||
|湯曰：「格女眾庶，來，女悉聽朕言。匪台小子敢行舉亂，有夏多罪，予維聞女眾言，夏氏有罪。予畏上帝，不敢不正。今夏多罪，天命殛之。今女有眾，女曰：『我君不恤我眾，捨我嗇事而割政』。女其曰：『有罪，其柰何』？夏王率止眾力，率奪夏國。眾有率怠不和，曰：『是日何時喪？予與女皆亡』！夏德若茲，今朕必往。爾尚及予一人致天之罰，予其大理女。女毋不信，朕不食言。女不從誓言，予則帑僇女，無有攸赦。」|**商湯**說：「來，你們眾人，到這兒來，都仔細聽著我的話：不是我個人敢於興兵作亂，是因為**夏桀**犯下了很多的罪行。我雖然也聽到你們說了一些抱怨的話，可是**夏桀**有罪啊，我畏伐上天，不敢去征伐。現在你們眾人說：『我們的國君不體卹我們，拋開我們的農事不管，卻要去徵伐打仗。』你們或許還會問：『**夏桀**有罪，他的罪行究竟怎麼樣？』**夏桀**君臣加重徭役，耗盡了夏國的民力；又重加盤剝，掠光了夏國的資財。夏國的民眾都在怠工，不與他合作。他們說『這個太陽什麼時候消滅，我寧願和你一起滅亡』！夏王的德行已經到這種地步，現在我一定要去討伐他！希望你們和我一起來奉行上天降下的懲罰，我會重重地獎賞你們。你們不要懷疑，我絕對不會說話不算數。如果你們違抗我的誓言，我就要懲罰你們，概不寬赦！」||
|以告令師，作湯誓。於是湯曰：「吾甚武」，號曰武王。|**商湯**把這些話告訴傳令長官，寫了《湯誓》。當時**商湯**曾說「我很勇武」，因此號稱武王。||
|桀敗於有娀之虛，桀奔於鳴條，夏師敗績。|**夏桀**在**有娀**氏舊地被打敗，奔逃到**嗚條**，**夏**軍全軍崩潰。||
|湯遂伐三嵕，俘厥寶玉，義伯、仲伯作典寶。|**商湯**乘勝追擊，進攻忠於**夏桀**的三嵕<sup>1</sup>，繳獲了他們的寶器珠玉，**義伯**、**仲伯**二臣寫下了《典寶》，因為這是國家的固定財寶。|<sup>1</sup>嵕（音同「宗」）；|
|湯既勝夏，欲遷其社，不可，作夏社。伊尹報。|**商湯**滅**夏**之後，想換掉**夏**的社神，可是社神是遠古**共公**氏之子**句龍**，能平水土，還沒有誰比得上他，所以沒有換成，於是寫下《夏社》，說明夏社不可換的道理。||
|於是諸侯畢服，湯乃踐天子位，平定海內。|**伊尹**向諸侯公佈了這次大戰的戰績，自此，諸侯全都聽命歸服了，**商湯**登上天子之位，平定了天下。||
|湯歸至于泰卷陶，中壘作誥。|**成湯**班師回朝，途經泰卷時，中壘<sup>1</sup>作了朝廷的諫命。|<sup>1</sup>壘（音同「悔」）|
|既絀夏命，還亳，作湯誥：「維三月，王自至於東郊。告諸侯群后：『毋不有功於民，勤力乃事。予乃大罰殛女，毋予怨。』曰：『古禹、皋陶久勞于外，其有功乎民，民乃有安。東為江，北為濟，西為河，南為淮，四瀆已修，萬民乃有居。后稷降播，農殖百穀。三公咸有功于民，故後有立。昔蚩尤與其大夫作亂百姓，帝乃弗予，有狀。先王言不可不勉。』曰：『不道，毋之在國，女毋我怨。』」以令諸侯。|**湯**廢除了**夏**的政令，回到國都**亳**，作《湯諦》號令諸侯。 《湯諦》這樣記載：「三月，**殷**王親自到了東郊，向各諸侯國君宣布：『各位可不能不為民眾謀立功業，要努力辦好你們的事情。否則，我就對你們嚴加懲辦，那時可不要怪罪我。』<br>「 又說：「『過去**禹**、**皋陶**長期奔勞在外，為民眾建立了功業，民眾才得以安居樂業。當時他們東面治理了長江，北而治理了濟河，西面治理了黃河，南面治理了淮河，這四條重要的河道治理好了，萬民才得以定居下來。**后稷**教導民眾播種五穀，民眾才知道種植各種農作物。這三位古人都對民眾有功，所以，他們的後代能夠建國立業。也有另外的情況：從前**蚩尤**和他的大臣們在百姓中發動暴亂，上帝就不降福於他們，這樣的事在歷史上是有過的。先王的教誨，可不能不努力照辦啊！ 』<br>「又說：『你們當中如果有誰幹出違背道義的事，那就不允許他回國再當諸侯，那時你們也不要怨恨我。 』」湯用這些話告誡了諸侯。||
|伊尹作咸有一德，咎單作明居。|這時，**伊尹**又作了《咸有一德》，說明君臣都應該有純一的品德；**咎單**作了《明居》，講的是民眾應該遵守的法則。||
|湯乃改正朔，易服色，上白，朝會以晝。|**商湯**臨政之後，修改的曆法，把**夏曆**的寅月為歲首改為醜月為歲首，又改變了器物服飾的顏色，崇尚白色，在白天舉行朝會。||
|湯崩，太子太丁未立而卒，於是乃立太丁之弟外丙，是為帝外丙。|**商湯**逝世之後，因為太子**太丁**未能即位而早亡，就立**太丁**弟**外丙**為帝，這就是**外丙帝**。||
|帝外丙即位三年，崩，立外丙之弟中壬，是為帝中壬。|**外丙**即位三年，逝世，立**外丙**的弟弟**中壬**為帝，這就是**中壬帝**。||
|帝中壬即位四年，崩，伊尹乃立太丁之子太甲。|**中壬**即位四年，逝世，**伊尹**就擁立**太丁**之子**太甲**為帝。||
|太甲，成湯適長孫也，是為帝太甲。|**太甲**，是**成湯**的嫡長孫，是**太甲帝**。||
|帝太甲元年，伊尹作伊訓，作肆命，作徂后。|**太甲**元年，**伊尹**為諫訓**太甲**，作了《伊訓》、《肆命》、《徂後》。||
|帝太甲既立三年，不明，暴虐，不遵湯法，亂德，於是伊尹放之於桐宮。|**太甲帝**臨政三年之後，昏亂暴虐，違背了**湯王**的法度，敗壞了德業，因此，**伊尹**把他流放到**湯**的葬地桐宮。||
|三年，伊尹攝行政當國，以朝諸侯。|此後的三年，**伊尹**代行政務，主持國事，朝會諸侯。||
|帝太甲居桐宮三年，悔過自責，反善，於是伊尹乃迎帝太甲而授之政。|**太甲**在桐宮住了三年，悔改自責，重新向善，於是**伊尹**又迎接他回到朝廷，把政權交還給他。||
|帝太甲修德，諸侯咸歸殷，百姓以寧。|從此以後，**太甲帝**修養道德，諸侯都來歸服，百姓也因此得以安寧。||
|伊尹嘉之，乃作太甲訓三篇，褒帝太甲，稱太宗。|**伊尹**對**太甲帝**很讚賞，就作了《太甲訓》三篇，讚揚**帝太甲**，稱他為**太宗**。||
|太宗崩，子沃丁立。帝沃丁之時，伊尹卒。|**太宗**逝世後，兒子**沃丁**即位。**沃丁**臨政的時候，**伊尹**去逝了。||
|既葬伊尹於亳，咎單遂訓伊尹事，作沃丁。|在**亳地**安葬了**伊尹**之後，為了用**伊尹**的事蹟垂訓後人，**咎單**作了《沃丁》。||
|沃丁崩，弟太庚立，是為帝太庚。|**沃丁**逝世，他的弟弟**太庚**即位，這就是**太庚帝**。||
|帝太庚崩，子帝小甲立。|**太庚**逝世，兒子**小甲**即位；||
|帝小甲崩，弟雍己立，是為帝雍己。|**小甲帝**逝世，弟弟**雍已**即位，這就是**雍已帝**。||
|殷道衰，諸侯或不至。|到了這個時候，**殷朝**的國勢已經衰弱，有的諸侯就不來朝見了。||
|帝雍己崩，弟太戊立，是為帝太戊。|**雍已**逝世，他的弟弟**太戊**即位。這就是**太戊帝**。||
|帝太戊立伊陟為相。|**太戊**任用**伊陟**<sup>1</sup>為相。|<sup>1</sup>陟（音同「治」）；|
|亳有祥桑谷共生於朝，一暮大拱。|當時國都**亳**出現了桑樹和楮<sup>1</sup>樹合生在朝堂上的怪異現象，一夜之間就長得有一摟粗。|<sup>1</sup>楮（音同「儲」）；|
|帝太戊懼，問伊陟。伊陟曰：「臣聞妖不勝德，帝之政其有闕與？帝其修德。」|**太戊帝**很害怕，就去問**伊陟**。**伊陟**對**太戊帝**說：「我曾經聽說，妖異不能戰勝有德行的人，會不會是您的政治有什麼失誤啊？希望您進一步修養德行。」||
|太戊從之，而祥桑枯死而去。|**太戊**聽從了**伊陟**的規諫，那怪樹就枯死而消失了。||
|伊陟贊言于巫咸。巫咸治王家有成，作咸艾，作太戊。|**伊陟**把這些話告訴了**巫鹹**。**巫鹹**治理朝政有成績，寫下《鹹艾<sup>1</sup>》、《太戊》，記載了**巫鹹**治理朝政的功績，頌揚了**太戊帝**的從諫修德。|<sup>1</sup>艾（音同「義」）|
|帝太戊贊伊陟于廟，言弗臣，伊陟讓，作原命。|**太戊帝**在太廟中稱讚**伊陟**，說不能像對待其他臣下一樣對待他。**伊陟**謙讓不從，寫下《原命》，為的是重新解釋**太戊**之命。||
|殷復興，諸侯歸之，故稱中宗。|就這樣，**殷**的國勢再度興盛，諸侯又來歸服。因此，稱**太戊帝**為**中宗**。||
|中宗崩，子帝中丁立。帝中丁遷于隞。|**中宗**逝世，兒子**中丁**繼位。**中丁帝**遷都於**隞**<sup>1</sup>。|<sup>1</sup>隞（音同「熬」）；|

|紂怒曰：「吾聞聖人心有七竅。」剖比干，觀其心。|**紂**大怒，說：「我聽說聖人的心有七個孔。」於是剖開**比干**的胸膛，挖出心來觀看。||
|箕子懼，乃詳狂為奴，紂又囚之。|**箕子**見此情形很害怕，就假裝瘋癲去給人家當了奴隸。**紂**知道後又把**箕子**囚禁起來。||
|殷之大師、少師乃持其祭樂器奔周。周武王於是遂率諸侯伐紂。|**殷**國的**太師**、**少師**拿著祭器、樂器，急急逃到**周**國。**周武王**見時機已到，就率領諸侯討伐殷**紂**。||
|紂亦發兵距之牧野。|**紂**派出軍隊在**牧野**進行抵抗。||
|甲子日，紂兵敗。紂走入，登鹿臺，衣其寶玉衣，赴火而死。|週曆二月初五甲子那一天，**紂**的軍隊被打敗，**紂**倉皇逃進內城，登上鹿台，穿上他的寶玉衣，自焚而死。||
|周武王遂斬紂頭，縣之［大］白旗。殺妲己。釋箕子之囚，封比干之墓，表商容之閭。|**周武王**砍下**紂**的頭，掛在太白旗竿上示眾。**周武王**又處死了**妲己**。釋放了**箕子**，修繕了**比干**的墳墓，表彰了**商容**的里巷。||
|封紂子武庚、祿父，以續殷祀，令修行盤庚之政。殷民大說。於是周武王為天子。|封**紂**的兒子**武庚**祿父，讓他承續**殷**的祭祀，並命令他施行**盤庚**的德政，**殷**的民眾非常高興。於是，**周武王**做了天子。||
|其後世貶帝號，號為王。而封殷後為諸侯，屬周。|因為後世人貶低「帝」這個稱號，所以稱為「王」。封**殷**的後代為諸侯，隸屬於**周**。||
|周武王崩，武庚與管叔、蔡叔作亂，成王命周公誅之，而立微子於宋，以續殷後焉。|**周武王**過世後，**武庚**和**管叔**、**蔡叔**聯合叛亂，**周成王**命**周公旦**詛殺他們，而把**微子**封在**宋國**，來延續**殷**的後代。||
|太史公曰：余以頌次契之事，自成湯以來，采於書詩。契為子姓，其後分封，以國為姓，有殷氏、來氏、宋氏、空桐氏、稚氏、北殷氏、目夷氏。孔子曰，殷路車為善，而色尚白。| **太史公**說：我是根據《詩經》中的《商頌》來編定**契**的事蹟的，自**成湯**以來，很多史實材料採自《尚書》和《詩經》。**契**為**子**姓，他的後代被分封到各國，就以國為姓了，有**殷**氏、**來**氏、**宋**氏、**空桐**氏、**稚**氏、**北殷**氏、**目夷**氏等。**孔子**曾經說過，**殷**人的車子很好，崇尚白色。||
